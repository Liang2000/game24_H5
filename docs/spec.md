# game24 规格说明

> 依据：`README.md` + 需求澄清（grilling）达成的共识。领域术语见 `CONTEXT.md`。

## 1. 概述

一款 Windows 桌面版 24 点益智小游戏。玩家用随机 4 张牌，通过加、减、乘、除和括号凑出 24。提供两大模块：**单人挑战**与**24 点提示**。

## 2. 技术选型

- 语言：Python 3.10+
- GUI：PySide6（Qt）
- 打包：PyInstaller（`--onefile`，Windows 独立 exe）
- 数据存储：本地 JSON 文件（成绩记录）

## 3. 领域规则

### 3.1 牌组

- 去掉大小王的标准 52 张扑克牌。
- 花色仅作装饰，不影响计算。

### 3.2 牌面数值

| 牌面 | 数值 |
| --- | --- |
| A | 1 |
| 2–10 | 牌面数字 |
| J | 11 |
| Q | 12 |
| K | 13 |

## 4. 核心玩法

1. 随机抽取 4 张牌，得一组待计算数字。
2. 仅用 `+`、`−`、`×`、`÷` 四则运算，可自由加括号。
3. 4 个数字必须全部使用，且各用一次。
4. 结果恰为 24 即解题成功；无解则判无解。

## 5. 求解器规格

- 精确有理数运算（`fractions.Fraction`），避免浮点误差。
- 中间结果允许分数与负数；除数不能为 0。
- 能判定给定 4 个数是否可解（用于「无解」评判）。
- 列出所有「本质不同」解：仅因加法/乘法交换律或结合律而不同者视为同一条；运算符或结构不同的视为不同解。
- 解法数量上限 20 条（不足则全列）。

## 6. 单人挑战模块

### 6.1 关卡

- 每关 10 道题。
- 各关规则相同，关卡号递增。

### 6.2 计分

| 行为 | 得分 |
| --- | --- |
| 正确（含正确判断「无解」） | +1 |
| 跳过 | 0 |
| 错误 | −1 |

- 分数可为负。
- 累计 ≥ 8 分即**立即过关**（结束本关，进入下一关）。
- 打满 10 题不足 8 分 → 判失败，可重玩本关。

### 6.3 单题流程

1. 随机抽 4 张牌，显示在界面。
2. 玩家输入表达式点【提交】，或点【无解】。
3. 系统验证：
   - 表达式合法且结果 = 24 → 提示「你太棒了，完全正确。」，+1 分。
   - 表达式错误 → 提示「很遗憾，你的算法出错！」，−1 分。
   - 点【无解】且确无解 → +1 分；若实际有解 → 判错，−1 分。
4. 进入下一题，或触发过关 / 失败结算。

### 6.4 表达式校验

- 支持 `+ − × ÷` 与括号，兼容 `* /` 及全角符号。
- 校验：仅使用给定 4 个数值、各一次、运算符合法、结果 = 24。

## 7. 24 点提示模块

- 界面提供 4 个数字框，用于显示已选数字。
- 数字框下方提供 13 张数字卡片：A、2、3、…、10、J、Q、K（对应数值 1–13）。
- 点击一张卡片 → 选中该值，填入第一个空数字框；同一卡片可重复点击（允许重复数字）。
- 点击已填数字的数字框 → 清空该框，以便重新选择卡片。
- 4 个框填满后，点【提示】列出多种解法。
- 示例（3, 8, 8, 9）：

```
3 * 8 * (9 - 8) = 24
3 * 8 / (9 - 8) = 24
3 * (9 - 8 / 8) = 24
```

## 8. 成绩记录（高光时刻）

- 本地 JSON 文件保存。
- 每条记录字段：`时间戳、关卡号、得分、是否过关、用时`。
- 挑战界面点【高光时刻】按钮，展示历史记录（游戏时间与闯关情况）。

## 9. 界面流程

```
主界面（两大入口）
├── 单人挑战
│   ├── 显示 4 张牌 + 表达式输入框
│   ├── 按钮：【提交】【无解】【高光时刻】
│   └── 显示当前得分 / 关卡号
└── 24 点提示
    ├── 4 个数字框（显示已选卡片，点击清空）
    ├── 下方 13 张数字卡片：A、2–10、J、Q、K（点击选择）
    ├── 按钮：【提示】
    └── 解法列表
```

2. **解法排序规则**：默认按规范化表达式字符串升序排列。
