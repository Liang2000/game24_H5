# game24



一款益智小游戏

### 一、游戏基础设定

* ‌**使用牌组**‌：一副去掉大小王的标准扑克牌，共52张。
* ‌**牌面数值定义**‌：A代表数字1，J代表11，Q代表12，K代表13，其余数字牌按牌面数字取值。

### 二、核心玩法规则

1. 随机抽取4张牌，得到一组待计算的数字。
2. 仅允许使用加、减、乘、除四则运算，可自由添加括号调整运算优先级。
3. 4个牌面对应的数字必须全部使用，且每张牌只能使用一次。
4. 最终运算结果必须精确等于24，即为解题成功。如无解则提示该组牌无解。

### 三、常用解题技巧

* 优先凑出3×8、4×6、2×12的固定乘法组合，对应口诀“见3凑8，见4凑6，见2凑12”。
* 利用减法组合，凑出25-1、27-3、28-4、30-6这类结果为24的算式。
* 借助0和1的运算特性，通过“加减抵消”“乘除归一”的方式灵活调整运算结果。
  
  

本游戏提供三大功能模块

1、单人挑战游戏：

1.1 每一关10组题目，每次出1组，正确得1分（含判断为无解），跳过不得分，错误扣1分。8分闯关

1.2 每1组游戏，随机抽取4张牌，显示在交互界面上，玩家可以输入计算方案，点【提交】进行算法验证，错误则提示，“很遗憾，你的算法出错！” ；正确则提示：“你太棒了，完全正确。”。如这组牌无解，玩家也判断为无解，点【无解】按钮，判断计分后进入下一组。

1.3 在本地保存玩家本次游戏得分记录，界面上可以点【高光时刻】按钮，显示玩家之前游戏时间及闯关情况



2、提示24算法：

2.1 交互界面提供4个数字框，玩家选择4个数字卡片（下方提供A,2至10，J,Q,K  数字卡片），点【提示】按钮，列出多种解法。点【清空】按钮，清除4个数字框内容。

例如：输入3，8，8，9，提供解法：

 3 * 8 * (9 - 8) = 24

 3 * 8 / (9 - 8) = 24

 3 * (9 - 8 / 8) = 24



3、组合速查：

3.1 界面提供 A–K 共 13 张牌面卡片（两行排列：第一行 7 张、第二行 6 张），最多可同时点选 4 张；下方列出所有「同时包含所选牌面」的可解组合（并列关系）。选中的卡片底色变为淡绿色。

3.2 再次点击已选中的卡片可取消选中；点击第二行末位的【清空】按钮一次清除全部选择。
